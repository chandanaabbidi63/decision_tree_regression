# Iris Decision Tree Classifier (Streamlit)

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## What it does
- Trains an `sklearn.tree.DecisionTreeClassifier` on the Iris dataset
- Lets you tune key hyperparameters in the sidebar
- Shows test accuracy and a confusion matrix
- Lets you enter feature values and predicts the Iris species
